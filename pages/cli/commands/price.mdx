# `price`

Checks the price to upload the specified number of bytes.

**Parameters**

<div className="-mt-6" />

- `-t`: The [token](/overview/supported-tokens) used for payment.
- `-n`: The network to check. Use `mainnet`.
- `--provider-url`: Optional RPC URL to use. 

## Example

```console
irys price 1000000 \
  -t ethereum
```
